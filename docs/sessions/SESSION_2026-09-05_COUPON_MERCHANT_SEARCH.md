# חיפוש חנויות בתוך קופונים וכרטיסים כלליים

## מטרת הפיצ׳ר

לאפשר למשתמש לבדוק איזה קופון קיים מתאים לחנות שבה הוא רוצה לקנות, גם כאשר שם החנות אינו מופיע ישירות על הקופון.

דוגמה: המשתמש מחפש LEGO. המערכת בודקת גם קופונים ישירים וגם כרטיסים כלליים כמו BUYME או XTRA, שיכולים להכיל בתוכם בתי עסק נוספים.

הפיצ׳ר מוגבל כרגע ל־`user_id = 1`.

## הזרימה במסך הקופונים

1. המשתמש מקליד שם חנות בשדה החיפוש.
2. החיפוש באינטרנט אינו מתחיל בזמן ההקלדה.
3. מופיע כפתור פעולה מפורש: „איזה קופון שלי מתאים ל־[שם החנות]?”
4. לאחר לחיצה מוצג אזור התקדמות בתוך העמוד עם אנימציית טעינה.
5. אזור ההתקדמות אינו Modal. אפשר להמשיך להשתמש באפליקציה בזמן הבדיקה.
6. המערכת בודקת התאמות ישירות והתאמות בתוך כרטיסים כלליים.
7. אם נמצאו כמה אפשרויות, מוצג מספר הקופונים שנמצאו.
8. לחיצה על כפתור התוצאה פותחת מסך בחירה מרוכז בתוך Modal.
9. במסך הבחירה מוצגים כל הקופונים המתאימים, עם:
   - שם החברה או הכרטיס.
   - יתרה זמינה.
   - סיבת ההתאמה.
   - לוגו החברה.
10. רק לאחר בחירה מפורשת עוברים לעמוד פרטי הקופון. אין מעבר אוטומטי לקופון הראשון.

קיימים גם מצבי שגיאה, אין תוצאות ובדיקה חוזרת.

## הזרימה בעמוד פרטי קופון

בעמוד פרטי קופון נוסף הכפתור „איפה אפשר לממש?”.

בלחיצה נפתח Modal שמציג:

- אנימציית טעינה בזמן החיפוש.
- רשימת בתי עסק שמכבדים את הקופון.
- הסבר קצר לכל התאמה.
- קישור למקור הרשמי עבור כל בית עסק.
- אפשרות לפתוח את המקור בדפדפן הפנימי של האפליקציה.
- מצב שגיאה עם כפתור לבדיקה חוזרת.
- מצב ריק כאשר לא נמצאה רשימה שאפשר לאמת.

המערכת אינה מציגה בית עסק ללא מקור רשמי שמאמת את ההתאמה.

## צד שרת וחיפוש באינטרנט

החיפוש מתבצע בפונקציית Supabase Edge Function בשם:

`search-coupon-merchants`

הפונקציה תומכת בשני מצבים:

### בדיקת חנות מול כל הקופונים

קלט:

```json
{
  "query": "LEGO"
}
```

הפונקציה:

1. שולפת את הקופונים הפעילים של `user_id = 1`.
2. מאתרת התאמות ישירות לפי שם החברה.
3. שולחת ל־OpenAI רק מועמדים שדורשים בדיקת אינטרנט.
4. משתמשת ב־Web Search כדי לבדוק מקורות רשמיים ועדכניים.
5. מחזירה התאמות ברמת ודאות `high` או `medium` בלבד.

### פירוט בתי עסק של קופון מסוים

קלט:

```json
{
  "mode": "directory",
  "couponId": 123
}
```

הפונקציה:

1. מוודאת שהקופון שייך ל־`user_id = 1`.
2. מחפשת רשימת בתי עסק במקורות רשמיים של מנפיק הקופון.
3. מחזירה שם בית עסק, הסבר וקישור למקור.
4. מסירה כפילויות.
5. דוחה קישורים שלא הופיעו בפועל במקורות של החיפוש.

## אבטחה ופרטיות

- הגישה בצד השרת מותרת רק למשתמש המחובר שמזהה החשבון שלו הוא `1`.
- השאילתות למסד מסוננות גם לפי `user_id = 1`.
- קוד הקופון, CVV וקישור המימוש הסודי אינם נשלחים ל־OpenAI.
- נשלחים רק נתונים הדרושים לזיהוי סוג הכרטיס: חברה, תיאור ומקור.
- תשובות OpenAI נדרשות לעמוד בסכמת JSON קשיחה.
- קישורי מקור מתקבלים רק מרשימת המקורות שהוחזרה מכלי החיפוש.
- בקשות רשת עוברות דרך מנגנון `safeFetch` הקיים.
